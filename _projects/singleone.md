## 한 줄로

Admin 페이지가 없던 시점에 합류해, **Admin 구축 → 도달(reach) 예측 → 배치 업로드 검증 → S3 데이터 연동 → 신규 연동 데이터 기획**까지 도메인을 하나씩 넘겨받으며 오너십을 넓혀 왔습니다.

## 도달 예측

- 매 요청마다 외부 매체 API를 부르던 구조를 **DB 우선 캐싱 조회**로 전환해 평균 응답 시간 50% 단축. 2026년 재구현 때도 같은 원칙 유지
- 지역(region_group → region → city) 계층과 연령·성별 인구 데이터 테이블을 직접 설계
- 매체별 예측 오디언스 사이즈와 CPM × 예산 기반 기대 노출을 비교해 **타깃·예산 설정의 적절성을 사전 검증**하는 로직으로 확장 (ML이 아닌 규칙 기반)
- 예측 요청은 기존 Redis/RQ 워커 구조 위에 비동기 태스크로 분리

## 배치 업로드 · 데이터 연동

- CSV 업로드를 전체 성공/실패 이분법에서 **행 단위 에러 수집 + 207 Multi-Status** 응답으로 재설계 — 이후 기능들이 이 규격 위에서 확장
- UTF-8/CP949/EUC-KR 인코딩, 대용량 Excel OOM 해결, 외부 API 대량 호출은 25개 단위 + `asyncio.gather`로 실패 반경 제한
- Mynavi가 S3에 올리는 광고 운용·광고주 데이터의 **정합성 검증 배치 + 오류 시 자동 메일 알림** 개발 완료(현재 안정화)
- 2026.08부터 신규 연동 기능을 **데이터 기획 단계부터** 참여 — 필요 데이터 정의, 스키마, 백엔드 아키텍처

## 같은 시기의 데이터 제품

- **LinkONE** (2025.05–08, PM · 백엔드) — 인플루언서 캠페인의 유입→공유→장바구니→구매 퍼널과 전환 지표(AOV, Cart→Purchase Rate, Brand Share)를 정의하고 Batch ETL과 대시보드를 구축. 수작업 리포트 대비 집계 90% 이상 자동화(사내 기준)
- **Qoo10 광고 성과 분석** (2025.07–) — 랭킹 Top 200(11개 카테고리)을 1시간 단위로 축적해 광고 성과와 시장 지표를 매칭하는 대시보드, 향후 성과 예측·MAB 추천을 위한 광고 이력 피처 스키마 정의(모델은 계획 단계)
